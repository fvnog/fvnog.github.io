# Fernando Nogueira · Portfólio

[Ver portfólio](https://fvnog.github.io/)

Portfólio de desenvolvedor sênior e Tech Lead, com tema dark, apresentação minimalista e foco em sistemas reais: backend, arquitetura, IA aplicada, automação e infraestrutura.

## Destaques

- Foto de perfil local, sem dependência do avatar do GitHub.
- Case do ecossistema PLOX Brasil: JobAI, JobAI Systems, JobAI Server e portal público.
- Stack e entregas revisadas a partir do código dos projetos.
- Português e inglês, com preferência de idioma persistida quando o navegador permite.
- Layout responsivo, HTML semântico, foco visível e suporte a movimento reduzido.
- Metadados SEO, Open Graph e JSON-LD.

## Execução local

Site estático, sem dependências ou etapa de build:

```sh
python3 -m http.server 8108
```

Acesse `http://localhost:8108`.

## Estrutura

- `index.html`: conteúdo e traduções.
- `css/style.css`: tema dark e layout responsivo.
- `js/main.js`: troca de idioma.
- `img/foto-perfil.png`: fotografia fornecida pelo titular.

## Publicação

GitHub Pages publica a raiz da branch `main`. Nenhuma chave, configuração privada ou código dos sistemas de produção é incluído neste repositório.
